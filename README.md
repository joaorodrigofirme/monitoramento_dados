# 📊 Monitoramento de Dados — Governança

Análise de governança de dados das avenidas (ADS, CRMBACK, Giftback, Presenteia, ValeBonus),
cobrindo a camada de **Metric Views**, **Dashboards (Power BI)** e **Agentes (Genies)**.

## Objetivo

Levar o ecossistema ao estado em que **toda métrica vem de um Metric View** e **todo dado
não-métrico vem de tabela gold modelada**, com os MVs consumindo apenas gold (ideal) ou silver (tolerável).
